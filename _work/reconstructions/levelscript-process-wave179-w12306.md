## What changed (all semantically identical)

1. **Pre-switch mission chain reordered.**  The source order of the
   `else if (mission == …)` blocks after the shared active tail was
   `5, 26, 50, 51`.  The original compares `26` before `5` (disasm
   `0x13812a` is the `==5` test but the `bne` target `0x1382dc` is the
   `==26` test; the two blocks are laid out `5 body / 26 check`).  Moving
   the `26` block ahead of the `5` block reproduces that layout:

   ```
   -    else if (mission == 5) { ... }
   -    else if (mission == 26 && inAlienOrbit()) { ... }
   +    else if (mission == 26 && inAlienOrbit()) { ... }
   +    else if (mission == 5) { ... }
   ```

   This alone is +370 raw (`53,082 → 53,452`) and keeps size/`.rel.plt`
   exact.  The `B` chain (`81,78,89,106,95`) must stay in its base order:
   swapping `89`/`106` gives a much larger raw win (`54,850`) but flips the
   first-reference order of `PlayerFixedObject::moveForward` and
   `PlayerEgo::setFreeLookMode`, which permutes `.rel.plt` (10 entries) and
   drops byte_exact by 5.  Only `81,78,89,106,95` is both size-exact and
   `.rel.plt`-clean among the 60 permutations with `89` before `106`.

2. **Drop the `Status *status` top-level alias** (call `Globals::status`
   directly in the two dispatch tests).  +1 raw.

3. **Drop the `Status *st` alias in mission 106** (`field_68` write) and
   in the mission-113 block (`field_5c`/`field_68` writes).  +4 raw.

4. **Drop `Level *lvl1613`, `Level *lvl2791`, `Level *lvl4280` and the
   mission-10 `Level *lvl` aliases**, calling `m_pLevel` directly.  The
   `lvl4280` removal matches the original's `ldr r6,[sp,#80]; ldr r0,[r6]`
   shape.  +~15 raw.

5. **Remove the `__builtin_expect(wingman->isWingMan(), 0)` on the first
   wingman loop and add it to the second loop.**  The original has both
   loops in the bottom-tested `cbz` shape; the expect on the first loop
   produced the `cbnz` + extra `b.n` form (8 B larger).  Swapping the
   expect between the loops fixes both shapes.  +66 raw.

## What was tried and rejected

* `else if (mission == 5)` → `if (mission == 5)` (tail becomes a separate
  `if`): raw 55,182, size 57,184 (**-48**), and `.rel.plt` changes.
* Faithful two-chain split (`if (m_bStartSequence) …` then a separate
  `if (mission == 5) … else if`): raw 55,799, size 57,552 (**+320**).
* `mkchain` nested-tail reorder `5,81,26,78,50,89,106,95,51`: raw 55,547,
  size 57,220 (**-12**).
* B-chain permutations: `81,78,89,95,106` gives raw 55,366 with size
  57,200 (**-32**, `.rel.plt` clean); the missing 32 B are 20 B of cold
  landing-pad code plus 3 final-pool words.  No small edit recovered them.
* `81,78,106,89,95`: raw 54,850, size exact, but `.rel.plt` permuted.
* `Status *st` at mission 113 removed on base: +19 raw but the whole
  combination is subsumed by the loop-expect change.
* `int i` vs `unsigned int i` in the wingman loops: neutral.
